Recording protocol

Keep every take comparable

  1. Hold the setup still.Use the same input gain for the paired noise and command.
  2. Capture noise first.Record one second with no talking or handling sounds.
  3. Speak after the cue.Center one complete command inside the 1.25-second clip.
  4. Change one condition.Vary speaker, session, distance, volume, or environment deliberately.
  5. Protect the test set.Assign entire sessions—not random clips—to validation or test.
Recommended format Mono PCM WAV, 48 kHz, 16- or 24-bit. Other formats are accepted but should be converted before training.

Collection guide

Every sample type you need

Collect real examples first. Controlled noise mixing expands the dataset later.

01

Effect commands

Record echo, reverb, high pitch, low pitch, and bypass. Capture soft, normal, and loud speech at 0.3, 1, and 2 meters.

  • 1.25 seconds each
  • 50 takes per speaker per command
  • At least three sessions
02

Paired calibration noise

Before a noisy command, record the same environment with nobody speaking. Do not move the source or change gain between clips.

  • 1 second each
  • Pair with every real noisy command
  • No speech or handling noise
03

Unknown speech

Record unrelated words, sentences, names, and partial commands. Include acoustically similar phrases that should not activate an effect.

  • 1.25 seconds each
  • Multiple speakers
  • Clean and noisy conditions
04

Noise-only negatives

Capture fan, HVAC, hum, static, music, conversation, traffic, keyboard sounds, and impacts without a valid command.

  • 1.25 seconds each
  • Quiet through very loud
  • Label as unknown
05

Silence

Record the system’s real noise floor in every room and with every input setup. Silence is not a file filled with digital zeros.

  • 1.25 seconds each
  • Keep normal input gain
  • Include low room ambience
06

Held-out validation

Reserve complete sessions or speakers before augmentation. Never place altered copies of one recording in multiple splits.

  • 15% validation
  • 15% test
  • No augmentation leakage
07

SNR augmentation

In Python, mix clean commands with separate noise recordings at controlled levels and run the exact FPGA preprocessing model.

  • 20, 10, 5, and 0 dB SNR
  • Different noise segment for calibration
  • Keep original WAV files
08

Hardware test vectors

Choose representative clean, noisy, silence, and unknown clips for bit-exact Python-to-RTL feature comparison.

  • Do not train on these clips
  • Preserve raw PCM and metadata
  • Cover overflow edge cases
